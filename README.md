三国杀单挑 (astrbot_plugin_sanguosha)
在聊天软件里直接打三国杀！这是一个纯代码结算的 1v1 文字对局插件，不吃大模型的 token。108 张牌堆、判定、装备、还有各种界包武将技能全都在本地跑完，主打一个原汁原味。

怎么玩？
直接在群里（或私聊）发 /三国杀 就能开局（不加斜杠直接说“三国杀”也行）。
开局后会发给你 3 个武将，回 1 2 3 选一个，你就是先手。

对局全靠发指令交互：

回 数字 = 打出手牌（比如回 1 就是打出 1 号手牌）

回 字母 A/B/C = 发动武将技能

回 0 = 结束出牌阶段 / 放弃当前询问

回 ？ = 忘了技能是啥？随时查说明书

不想玩了就发 /结束 或 /退出三国杀

对了，如果打错了或者想跑路，发 重开 可以强行重开一局（需要二次确认，防手滑）。

面板长啥样？
没做花里胡哨的图片，全是纯文字排版。等待你操作的时候，面板会告诉你当前局势、双方血线、判定区和装备区。

等你出牌/出闪/求桃的时候，面板会切换成对应的提示，照着提示回数字就行。

武将池
目前塞进去了 30 个武将，技能名都换成了中文，打起来比较顺手。
包含了曹操、司马懿、界关羽、界张飞、诸葛亮、孙尚香、华佗、界吕布等等。

规则细节（写都写了，尽量还原）
牌堆是真实洗牌抽牌的，花色点数全参与结算。

乐不思蜀非红桃跳过出牌；兵粮寸断非梅花跳过摸牌；闪电黑桃 2-9 吃 3 点雷伤。

八卦阵判红当闪、仁王盾黑杀无效、藤甲普杀无效、青釭剑破防具。

顺手牵羊 / 过河拆桥可以自己挑目标：手牌（随机抽 1 张）、装备区、判定区。

手牌上限 = 当前体力。
