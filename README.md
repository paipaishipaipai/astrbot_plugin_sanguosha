三国杀单挑 (astrbot_plugin_sanguosha)
在聊天软件里直接打三国杀！这是一个纯代码结算的 1v1 文字对局插件

怎么玩？
直接在群里（或私聊）发 /三国杀 就能开局（不加斜杠直接说“三国杀”也行）。
开局后会发给你 3 个武将，回 1 2 3 选一个，你就是先手。

对局全靠发指令交互：

回 数字 = 打出手牌（比如回 1 就是打出 1 号手牌）

回 字母 A/B/C = 发动武将技能

回 0 = 结束出牌阶段 / 放弃当前询问

回 ？ = 忘了技能是啥？随时查说明书

不想玩了就发 /结束 或 /退出三国杀

对了，如果打错了或者想跑路，发 重开 可以强行重开一局（需要二次确认，防手滑）。

全是纯文字排版。等待你操作的时候，面板会告诉你当前局势、双方血线、判定区和装备区。

等你出牌/出闪/求桃的时候，面板会切换成对应的提示，照着提示回数字就行。
