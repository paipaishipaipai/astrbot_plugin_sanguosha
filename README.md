# 三国杀单挑（astrbot_plugin_sanguosha）

纯本地结算的 1v1 三国杀文字局：108 张牌堆、判定、装备、22 名界包武将技能全部在插件内跑完，
不调用模型、不花 token，聊天窗口只负责发指令。

## 基础用法

**1. 开局**（`/` 开头，任一句都行）
```
/三国杀
/开一局三国杀
/陪我打三国杀
```
不加 `/` 直接说「三国杀」也能开；`／`（全角）同样认。

**2. 选将**：回 `1` / `2` / `3`，从发到的 3 张武将里挑一个，你是先手。

**3. 出牌**：回手牌前面的数字，就是打出那张牌。
```
1     → 打出 1 号手牌
A     → 发动 A 技能
0     → 结束出牌阶段
？    → 看技能说明
```

**4. 收摊**：回「/结束」/「/退出三国杀」/「/不玩了」；回「重开」要先答「确认」。

## 面板怎么看

```
───────── 对局 ─────────
◆ 局势　　双方血线（●）和手牌数
◆ 判定　　判定区里的乐不思蜀 / 兵粮寸断 / 闪电
◆ 装备　　武器 · 防具 · ±1 马
◆ 阶段　　当前该谁动、在等你回什么
───────── 武将 ─────────
◆ 武将　　将名 + 当前体力/体力上限
───────── 手牌 ─────────
◆ 手牌　　序号 · 花色点数 · 牌名（出牌就回这个序号）
───────── 技能 ─────────
◆ 技能　　A/B/C… 对应技能及发动时机
◆ 选项　　本回合能回什么
```
等牌时（出闪、出杀、弃牌、濒死求桃）面板会换成对应提示，照提示回数字就行。

## 指令一览

| 回什么 | 作用 |
| --- | --- |
| /三国杀 | 开一局（斜杠指令） |
| 数字 | 打出对应序号的手牌 |
| 字母 A/B/C | 发动对应技能 |
| 0 | 结束出牌阶段 / 放弃当前询问 |
| ？ 或 详情 | 只看技能说明 |
| 重开 | 询问是否放弃当前战局 |
| /结束 /退出三国杀 | 结束对局 |

## 规则要点

- 牌堆判定真实抽牌，花色点数参与结算
- 乐不思蜀非 ♥ 跳过出牌；兵粮寸断非 ♣ 跳过摸牌；闪电 ♠2–9 吃 3 点雷伤
- 八卦阵判红当闪、仁王盾黑杀无效、藤甲普杀无效、青釭剑破防具
- 顺手牵羊 / 过河拆桥由你自己挑目标：手牌（随机 1 张）· 装备区 · 判定区
- 手牌上限 = 当前体力
