# 三国杀单挑 (astrbot_plugin_sanguosha)

纯本地结算的 1v1 三国杀文字对局插件。不消耗大模型 Token，内置 108 张牌堆、判定、装备系统，并实装了 40 名武将及完整技能逻辑。

## 玩法模式

1. 单人模式（对战 AI）
在群聊或私聊中发送 /三国杀 即可开局。AI 会根据局势自动出牌。如果配置了 LLM，AI 会结合当前人格和战况做出反应，该对话不会污染正常聊天记录。

2. 双人模式（群内开房）
群内发送 /三国杀双人 建房，朋友发送 /三国杀加入。为了防作弊，选将和出牌环节会在机器人的私聊中进行，群内仅播报胜负和关键战况。

## 指令说明

单人模式
/三国杀：开始对局
/结束、/退出三国杀：强制结束当前对局
重开：重新发牌（需回复确认）

双人模式
群内发送 /三国杀双人 或 /三国杀加入
私聊机器人发送 看牌 查看选将和面板
群内或私聊发送 投降 认输

局内操作
回复数字：打出对应序号的手牌
回复字母（A/B/C...）：发动对应技能
回复 0：结束出牌阶段 / 放弃当前操作
回复 ？：查看技能说明
回复 &：装备丈八蛇矛时，打出手牌当杀

## 规则机制

牌堆判定：真实抽牌，花色点数参与结算。
延时锦囊：乐不思蜀非红桃跳过出牌；兵粮寸断非梅花跳过摸牌；闪电黑桃2-9受3点雷伤。
装备特效：八卦阵判红当闪、仁王盾黑杀无效、藤甲普杀无效、青釭剑破防具。
目标选择：顺手牵羊/过河拆桥可自选目标（手牌、装备、判定区）。
手牌上限：等于当前体力值。
